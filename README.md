## Descripción

Este repositorio contiene el trabajo de la Actividad 9, "Pensar antes de programar".

El objetivo es practicar el razonamiento lógico antes de escribir un programa, utilizando diagramas de flujo y pruebas de escritorio (Dry Run).

## Ejercicios

1. **El Sensor de Aprobación:** cálculo de un promedio y una condición para determinar si el estudiante está aprobado o debe ir a intensificación.
2. **El Bucle del Contador de Vidas:** repetición de instrucciones mientras queden vidas disponibles.
3. **Registro de Jugador en Memoria:** uso de una estructura Jugador con nickname, nivel y estado VIP.
4. **Control de Inventario con Arreglos:** recorrido de un vector para detectar posiciones sin stock.
